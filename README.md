# Student Management System

A console-based Student Management System developed using Java, JDBC, MySQL and Maven.

## Features

- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student
- Input Validation
- Duplicate Student ID Handling
- Email Validation
- MySQL Database Connectivity

## Technologies Used

- Java
- MySQL
- JDBC
- Maven
